## Security Audit Finding: C-01

**Severity:** 🔴 CRITICAL  
**Category:** Secret Exposure  
**Files Affected:**
- `backend/shared/auth.js` (Lines 11-12)
- `backend/src/security.ts` (Lines 5-6)

---

### Description

Real AWS Cognito User Pool ID (`us-east-1_R2j2oAqLJ`) and Client ID (`77205lmtu8fg6t1s3sgcidf7p9`) are hardcoded as fallback values in source code. Anyone who reads this public repository can target the Cognito pool for brute-force attacks, account enumeration, or unauthorized registration.

### Evidence

**`backend/shared/auth.js:L11-12`**
```javascript
const USER_POOL_ID = process.env.USER_POOL_ID || 'us-east-1_R2j2oAqLJ';
const CLIENT_ID = process.env.CLIENT_ID || '77205lmtu8fg6t1s3sgcidf7p9';
```

**`backend/src/security.ts:L5-6`**
```typescript
const USER_POOL_ID = process.env.USER_POOL_ID || 'us-east-1_R2j2oAqLJ';
const CLIENT_ID = process.env.CLIENT_ID || '77205lmtu8fg6t1s3sgcidf7p9';
```

### Remediation

Remove hardcoded fallback values and require environment variables. Fail fast if they are not set:

```typescript
const USER_POOL_ID = process.env.USER_POOL_ID;
const CLIENT_ID = process.env.CLIENT_ID;

if (!USER_POOL_ID || !CLIENT_ID) {
    throw new Error('FATAL: USER_POOL_ID and CLIENT_ID must be set as environment variables.');
}
```

### Checklist
- [ ] Remove hardcoded Cognito credentials from `backend/shared/auth.js`
- [ ] Remove hardcoded Cognito credentials from `backend/src/security.ts`
- [ ] Ensure `template.yaml` passes these as environment variables to all Lambda functions
- [ ] Rotate the Cognito Client ID (since it was exposed in public repo)
- [ ] Consider adding `.env` validation at startup
